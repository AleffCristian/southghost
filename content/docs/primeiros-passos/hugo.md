## Rodar localmente

Na raiz do projeto:

```powershell
hugo server
```

Abra:

```text
http://localhost:1313/
```

## Criar um novo artigo

Você pode criar o arquivo manualmente em `content/blog/` ou usar:

```powershell
hugo new content blog/meu-artigo.md
```

Depois ajuste o front matter do arquivo criado.
